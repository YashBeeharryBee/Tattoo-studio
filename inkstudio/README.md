# 🖤 INKSTUDIO — Premium Tattoo Studio Website

INKSTUDIO is a dark, cinematic, and highly interactive tattoo studio website built with React, Three.js, GSAP, Tailwind CSS, and a PHP/MySQL booking backend.

The website is designed to provide a premium digital experience for a modern tattoo studio, combining immersive 3D visuals, smooth animations, tattoo artwork, artist profiles, pricing, testimonials, and an appointment booking system.

---

## ✨ Features

### 🎨 Premium UI/UX

- Dark, almost-black cinematic design
- Minimal monochrome visual style
- Premium typography
- Responsive design
- Custom animated cursor
- Grain/noise overlay
- Smooth page transitions
- Interactive navigation
- Mobile-friendly interface

### 🧊 Interactive 3D Hero

The hero section includes an interactive 3D object built using React Three Fiber.

Features include:

- Interactive 3D object
- Mouse movement interaction
- Scroll-based interaction
- Dynamic lighting
- Low-key backlighting
- Metallic materials
- Cinematic presentation

### 🎬 Animations

The website uses several animation libraries to create a smooth and immersive experience.

- GSAP animations
- GSAP ScrollTrigger
- Framer Motion
- Lenis smooth scrolling
- Parallax effects
- Text reveal animations
- Image animations
- Scroll-triggered animations
- Interactive UI transitions

### 🖼️ Dynamic Gallery

The gallery provides a visual portfolio of tattoo work.

Features:

- Responsive masonry-style layout
- Tattoo category filtering
- Animated gallery transitions
- Framer Motion layout animations
- Responsive image presentation

### 👨‍🎨 Tattoo Artists

The Artists section presents the tattoo artists working at INKSTUDIO.

Each artist can include:

- Artist name
- Profile image
- Tattoo specialties
- Description
- Portfolio/social information

### 💰 Tattoo Pricing

The Pricing section displays tattoo services and prices in:

**Mauritian Rupees (Rs...)**

Pricing cards include:

- Service name
- Price
- Description
- Included services
- Booking call-to-action

### 📅 Booking System

INKSTUDIO includes a functional tattoo appointment booking system.

The booking system supports:

- Customer information
- Tattoo type selection
- Tattoo placement
- Tattoo size
- Preferred appointment date
- Tattoo description
- Reference image upload
- Client-side validation
- PHP backend processing
- MySQL database storage
- Web3Forms email notifications

### 📱 Responsive Design

The website is optimized for:

- Desktop
- Laptop
- Tablet
- Mobile
- Large screens
